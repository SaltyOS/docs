= Glossary
:description: Definitions of key terms used throughout the kernite documentation

[[asid]]ASID::
Address Space Identifier.  A hardware tag (16-bit on aarch64) stored in TTBR0 that distinguishes TLB entries belonging to different xref:memory/vspace.adoc[VSpaces].  Avoids full TLB flushes on context switch.  Not used on x86_64.

[[badge]]Badge::
A 64-bit value embedded in a xref:concepts/capabilities.adoc[capability] via the `mint` operation.  Delivered to the receiver during IPC to identify the sender.  Only endpoints and notifications can be badged.

[[bound-notification]]Bound notification::
A xref:ipc/notifications.adoc[notification] linked to a TCB via `TCB_BIND_NOTIFICATION`.  Signals on the bound notification wake the TCB even if it is blocked on an endpoint `Recv`.  See xref:ipc/notifications.adoc#bound-notifications[Bound Notifications].

[[capability]]Capability::
An unforgeable 32-byte token that names a xref:concepts/objects.adoc[kernel object] and carries xref:concepts/capabilities.adoc#rights[rights] to perform operations on it.  The sole mechanism for accessing kernel resources.

[[capref]]CapRef::
A 4-byte index (`u32`) into the xref:concepts/cspace.adoc#global-slot-array[global slot array].  Stored in xref:concepts/cspace.adoc[CNode] entries.  `CapRef::null()` uses `INVALID_SLOT = 0xFFFF_FFFF`.

[[cdt]]CDT (Capability Derivation Tree)::
A tree structure tracking parent-child relationships between capability slots.  Stored as linked-list pointers in xref:concepts/cspace.adoc[CapSlotMeta].  Enables xref:concepts/capabilities.adoc[revocation] of all capabilities derived from a given slot.

[[cnode]]CNode (Capability Node)::
A kernel object that stores an array of xref:concepts/cspace.adoc[CapRef] entries.  CNodes form a tree that constitutes a thread's CSpace.  Size: 16 to 65,536 slots (4 to 16 bits).

[[cow]]COW (Copy-on-Write)::
A memory optimization where parent and child xref:memory/memory-objects.adoc[MemoryObjects] share physical pages until a write occurs.  The write triggers a xref:memory/page-faults.adoc[page fault], and the kernel copies the page to the writer's private MO.

[[cspace]]CSpace (Capability Space)::
The namespace through which a thread addresses capabilities.  A tree of xref:concepts/cspace.adoc[CNodes] rooted at the thread's CSpace root (slot 2).

[[demand-paging]]Demand paging::
A xref:memory/page-faults.adoc[page fault] resolution strategy where physical frames are allocated on first access rather than at map time.  Marked in PTEs with `PRESENT=0, DEMAND=1`.

[[direct-map]]Direct physical map::
A permanent kernel mapping of all physical memory at offset `PHYS_MAP_OFFSET` (`0xFFFF_8000_0000_0000`).  Established during boot.  See xref:internals/memory-layout.adoc[Memory Layout].

[[edf]]EDF (Earliest Deadline First)::
The xref:scheduling/scheduler.adoc[scheduling algorithm] used by kernite.  The thread with the earliest absolute deadline runs first.  Combined with budget enforcement for temporal isolation.

[[endpoint]]Endpoint::
A synchronous IPC channel.  Sender and receiver rendezvous: one blocks until the other arrives.  See xref:ipc/endpoints.adoc[Endpoints].

[[fastpath]]Fastpath::
An assembly-optimized dispatch path for `Call` (syscall 2) and `ReplyRecv` (syscall 3) that handles short messages without capability transfer.  See xref:ipc/fastpath.adoc[IPC Fastpath].

[[frame]]Frame::
A 4 KB physical memory page.  The unit of allocation in the xref:memory/pmm.adoc[PMM].

[[frame-owner]]FrameOwner::
An enum tag on each physical frame in the xref:memory/pmm.adoc[PMM] that identifies the frame's current purpose: `Free`, `UntypedReserved`, `MoData`, `MoMeta`, `KernelPrivate`, `PageCache`, or `EmergencyReserve`.

[[global-slot-array]]Global slot array::
A boot-time allocated array storing all live xref:concepts/capabilities.adoc[capabilities] and their xref:concepts/cspace.adoc[metadata] (CDT links, untyped links, state).  Sized by `clamp(free_frames / 4, 768, 131_072)`.

[[ipc-buffer]]IPC buffer::
A 4,096-byte (one page) structure mapped into each thread's address space.  Carries overflow message registers (MR4-MR19), capability transfer slots, and receiver configuration.  See xref:ipc/endpoints.adoc[Endpoints].

[[ipi]]IPI (Inter-Processor Interrupt)::
A software-generated interrupt sent between CPUs.  Used for reschedule, TLB shootdown, and shutdown.  SGI on aarch64; APIC IPI on x86_64.

[[kernel-object]]Kernel object::
Any resource managed by the kernel: endpoint, notification, TCB, CNode, VSpace, frame, IRQ handler, I/O port, SchedContext, MemoryObject, or untyped memory.  See xref:concepts/objects.adoc[Object Model].

[[maple-tree]]Maple tree::
A B-tree variant used by xref:memory/vspace.adoc[VSpace] to track virtual address regions (xref:memory/vspace.adoc[VmAreas]).  Supports efficient range queries.

[[memory-object]]MemoryObject (MO)::
A page-granular memory abstraction that manages physical pages via a 4-level xref:memory/memory-objects.adoc[radix tree].  Supports commit, decommit, COW clone, and reverse mappings.

[[mint]]Mint::
A xref:concepts/capabilities.adoc[capability operation] that creates a badged copy of an endpoint or notification capability.  The minted capability cannot have `GRANT` right — it is a delegation dead-end.

[[notification]]Notification::
An asynchronous signaling primitive.  Stores a 64-bit bitmap of pending signal bits.  Never blocks the signaler.  See xref:ipc/notifications.adoc[Notifications].

[[pip]]PIP (Priority Inheritance Protocol)::
A mechanism that temporarily boosts a low-priority thread's effective deadline when a higher-priority thread blocks waiting for it.  Prevents priority inversion.  See xref:scheduling/threads.adoc[Threads].

[[pmm]]PMM (Physical Memory Manager)::
The kernel's bitmap-based frame allocator.  Sole owner of all physical frames.  See xref:memory/pmm.adoc[Physical Memory].

[[radix-tree]]Radix tree::
A 4-level tree (512 entries per node, 9 bits per level) used by xref:memory/memory-objects.adoc[MemoryObjects] to map page indices to physical addresses.  Capacity: 256 TB.

[[retype]]Retype::
The operation that carves typed xref:concepts/objects.adoc[kernel objects] from xref:concepts/untyped.adoc[untyped memory].  Invoke label `0x20`.

[[role-cap-table]]Role capability table::
The startup structure (`TronaCapTableV1`) that binds role IDs to resolved xref:concepts/capabilities.adoc[capabilities] in a spawned process's xref:concepts/cspace.adoc[CSpace].  Delivered to the child through the `AT_TRONA_CAP_TABLE` (`0x101C`) auxv tag.  Child processes look up service endpoints by role — there are no hardcoded CSpace slot numbers.  See xref:concepts/cspace.adoc#role-cap-table[Role-Based Capability Table].

[[role-id]]Role ID::
A 16-bit identifier used as the key into the <<role-cap-table,role capability table>>.  System roles occupy `0x0001`-`0x00FF`; process-local roles occupy `0x0100`-`0x0FFF` (`LOCAL_ROLE_BASE`..`LOCAL_ROLE_END`).

[[revoke]]Revoke::
A xref:concepts/capabilities.adoc[capability operation] that recursively destroys all capabilities derived from a given slot (depth-first CDT traversal).  The only operation that tears down an authority subtree.

[[sched-context]]SchedContext (Scheduling Context)::
A kernel object that encapsulates scheduling parameters: budget, period, deadline, priority.  Bound to a xref:scheduling/threads.adoc[TCB] via `SC_BIND`.

[[tcb]]TCB (Thread Control Block)::
A kernel object representing a schedulable thread.  Contains register save area, VSpace/CSpace pointers, IPC buffer address, FPU state, and scheduling state.  See xref:scheduling/threads.adoc[Threads].

[[tlb-shootdown]]TLB shootdown::
The process of invalidating stale TLB entries on remote CPUs after a page table modification.  Uses xref:scheduling/scheduler.adoc[IPI] to notify affected CPUs.  See xref:memory/vspace.adoc[Virtual Address Spaces].

[[untyped]]Untyped memory::
Raw physical memory from which all kernel objects are created via xref:concepts/untyped.adoc[retype].  The kernel has no general-purpose heap — all object allocation is explicit.

[[vmarea]]VmArea (Virtual Memory Area)::
A 24-byte descriptor in the xref:memory/vspace.adoc[Maple tree] that records a mapping: which xref:memory/memory-objects.adoc[MO] pages are visible at which virtual addresses with which permissions.

[[vspace]]VSpace (Virtual Address Space)::
A kernel object wrapping a hardware page table root.  Tracks mappings via a xref:memory/vspace.adoc[Maple tree].  Observer layer — owns no frames.

[[watermark]]Watermark::
The allocation cursor in an xref:concepts/untyped.adoc[untyped memory] region.  Advances forward on each retype.  Only resets via explicit `reset()` when no children exist.
